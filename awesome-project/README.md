#  FastAPI Practice Project

This project is a fundamental hands-on exercise designed to learn modern API development using **Python** and **FastAPI**. It covers everything from setting up a development environment to creating essential **CRUD** (Create, Read, Update, Delete) routes.

##  Core Concepts Learned

During this project, the following technical concepts were implemented:

* [cite_start]**Virtual Environment (venv):** Learned how to construct an independent library execution environment to avoid system setting conflicts.
* [cite_start]**FastAPI & Uvicorn:** Understood the relationship between the web framework (FastAPI) and the ASGI server (Uvicorn) that supports asynchronous processing.
* **HTTP Methods (Verbs):** Directly implemented the primary methods required for API communication:
    * **GET:** Data retrieval for the root path and specific ID items.
    * **PUT:** Modifying existing data via a JSON body.
    * **DELETE:** Simulating resource removal.
* **Pydantic Models:** Defined and used class-based data structures for automated data validation.
* **Automatic Documentation (Swagger UI):** Learned how to use the interactive API documentation automatically generated by FastAPI at the `/docs` endpoint.
